# HistoryProject.VladIovita

Acest proiect este un site educațional dedicat vieții și activității lui **Vlad Ioviță**, regizor și scriitor din Republica Moldova.  
Site-ul conține mai multe pagini:
- **Home** – introducere generală
- **Biography** – informații despre viața și cariera sa
- **Achievements** – realizările artistice și culturale
- **Contribution** – impactul asupra culturii și moștenirii

## Cum se folosește
1. Accesează linkul publicat pe GitHub Pages:  
   `https://username.github.io/HistoryProject.VladIovita/`
2. Navighează prin meniul principal pentru a explora paginile.
3. Poți viziona fragmente video și accesa linkuri externe pentru resurse suplimentare.

## Tehnologii folosite
- HTML5
- CSS3 (design responsiv, modern)
